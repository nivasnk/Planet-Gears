    Connect GitHub

    Connecting lets Publish save your changes straight to your GitHub repository. Your website then updates by itself in about a minute.
    1. Open GitHub → New fine-grained token.
    2. Repository access: “Only select repositories” → choose your website repo.
    3. Permissions → Repository → Contents: “Read and write”.
    4. Generate the token, copy it and paste it below.
